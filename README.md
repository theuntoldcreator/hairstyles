# Hairstyle Hub

![Hairstyle Hub Banner](public_html/images/hairsnapnew.png)

**Hairstyle Hub** is a progressive web app showcasing stylish haircuts and trends for everyone. Browse our curated galleries, read tutorials and join the community to share your own looks.

## ✨ Features

- **Responsive design** powered by Bootstrap
- **PWA ready** with service worker registration
- **Galleries for Men & Women** with hundreds of hairstyle ideas
- **Blog & Community links** to keep you inspired and connected
- **Instagram integration** right from the navigation menu

## Getting Started

1. Clone the repository
2. Install dependencies with `npm install`
3. Start a local server using `npm start`
4. Visit `http://localhost:8080` (default live-server port) to explore the site

## Project Structure

```
├── index.html          # Home page
├── men.html            # Gallery for men
├── women.html          # Gallery for women
├── css/                # Stylesheets
├── scss/               # SCSS sources

```
